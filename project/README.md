# CornerCue — Workstation & Posture Ergonomics Assistant

CornerCue is a non-intrusive desktop posture prompt designed for university students working multi-hour evening sessions on laptops. Instead of interrupting active typing with modal alerts, it detects an **8-second typing pause**, surfaces a keyboard-accessible corner cue (`Enter`/`Space`/`Esc`), and confirms posture resets with a `2800ms` status hold. **Current status:** Interactive prototype (HW08), mini design system & developer handoff specs (HW09), and evidence-based project presentation (HW10) completed.
